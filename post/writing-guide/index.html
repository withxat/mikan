Start with a file

Create a .md or .mdx file directly inside contents/posts/. Its filename becomes its URL: hello.mdx lives at /post/hello.

title: Hello, world
date: 2026-01-01
summary: My first note on this new blog.
category: notes
tags: [hello]
draft: false

A category must match an id in contents/categories.json. Drafts and posts dated in the future are excluded from the website, RSS feed, and sitemap. Rebuild the site when you are ready to publish.

Show your work

Code blocks include syntax highlighting:

const littleThings = ['a good book', 'a long walk', 'a new idea']

for (const thing of littleThings) {
  console.log(`Make room for ${thing}.`)
}

Add an image

Keep images in contents/posts/image/ and reference them with a relative path. In MDX posts, clicking an image opens a larger view.
